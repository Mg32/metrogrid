# 曲・効果音の元ファイル

ここに WAV を置いて `npm run sound` を実行すると、ブラウザで鳴らす形式（`src/assets/sound/` の .ogg と .m4a）に書き出されます。FFmpeg が必要です。

- ファイルがない音は、これまでどおりゲームが合成した音（仮のメトロノーム、仮の効果音）で鳴ります。1つずつ差し替えられます。
- 書き出したファイル（`src/assets/sound/`）も一緒にコミットしてください。公開用のビルドにはそちらが使われます。
- 書き出し直すのは、元のファイルが書き出しより新しいときだけです。すべてやり直すときは `npm run sound -- --force`。

## 曲（`music/`）

ファイル名はステージの名前です。

| ファイル | 場面 | BPM | 長さ（小節） | 前奏を含めた長さ |
|---|---|---|---|---|
| `music/TUTORIAL.wav` | チュートリアル | 100 | 20 | 50.4 秒 |
| `music/HUB.wav` | 拠点（家の中） | 116 | 繰り返す | 小節の倍数ならいくつでも |
| `music/STAGE1.wav` | STAGE 1 | 112 | 41 | 90.0 秒 |
| `music/STAGE2.wav` | STAGE 2 | 100 | 61 | 148.8 秒 |
| `music/STAGE3.wav` | STAGE 3 | 116 | 64 | 134.5 秒 |
| `music/STAGE4.wav` | STAGE 4 | 128 | 80 | 151.9 秒 |
| `music/STAGE5.wav` | STAGE 5 | 100 | 65 | 158.4 秒 |

- **BPM と長さはステージの定義と合わせます。** 曲のテンポに合わせてゲームが進むのではなく、ステージの定義（`tools/stagegen/` の `BPM`・`BARS`）の拍に合わせて曲が鳴ります。表の値は今のステージの定義で、変えるときはステージ側も変えます（下の「BPM と長さを試す」）。
- 4/4拍子で、曲の途中でテンポを変えない。
- **ステージの曲は、頭に1小節の前奏を入れます。** ゲームの「カウント」にあたる部分で、その次の小節の1拍目からプレイが始まります。前奏の長さを変えたいときは、`src/audio/conductor.ts` の `MUSIC_OFFSET` に、曲の頭から1小節目の1拍目までの秒数を書きます。
- 曲が終わった時点がタイムアップです。曲が短いと、終わる前に無音になります（開発サーバーでは、長さが合わないとブラウザのコンソールに出ます）。
- 拠点の曲は前奏なしで、曲の最後から頭へつながって繰り返します。拍がずれないよう、長さはちょうど小節の倍数にします。

## 効果音（`sfx/`）

| ファイル | 鳴る場面 |
|---|---|
| `sfx/pickup.wav` | 得点マスを取ったとき。連続で取って倍率が上がるほど、再生速度を上げて高く鳴らす（倍率1で元の高さ、倍率が1上がるごとに全音ずつ、倍率8まで） |
| `sfx/clear.wav` | ゴールしたとき（クリアのジングル）。ゴールの瞬間から鳴らす。結果の欄の行は、ゴールから 2.5・3.1・3.7・4.2 秒後に出る |
| `sfx/timeup.wav` | 時間切れで結果の画面が出たとき |
| `sfx/miss.wav` | 危険物に当たってミスしたとき（遊んでいるあいだ。曲に重ねて鳴る） |
| `sfx/fall.wav` | 景色の欠けたマスに落ちてミスしたとき |
| `sfx/bounce.wav` | 停止マスを押しっぱなしで通り抜けようとして、はじき返されたとき |
| `sfx/start.wav` | タイトルで始めたとき（少女が明かりのともった玄関へ入っていく 1.4 秒） |
| `sfx/portal.wav` | 拠点の入口に入ったとき（光の柱に包まれて闇に沈む 1.5 秒） |
| `sfx/back.wav` | Esc（HOME・SKIP・TITLE）で戻るとき（道が沈んで消えていく 1.3 秒） |
| `sfx/reveal.wav` | 拠点に新しい入口が現れるとき（拠点に戻った瞬間から。道がせり上がり始めるのは 1.0 秒後）と、チュートリアルで少女が現れるとき（読み込みが終わった瞬間から。光が降りてきて、1.2 秒後に少女の姿になる） |
| `sfx/homecoming.wav` | ステージを初めてクリアして家に帰ってくるとき（家の部分が戻っていくのが 0.9〜3.3 秒、戻りきって明かりがともるのが 3.3 秒） |
| `sfx/upstairs.wav` | 二階へ昇ると決めて、少女が階段を昇るとき（0.22 秒ごとに 1 段、6 段） |
| `sfx/select.wav` | ボタンで選ぶ・切り替えるとき（確認の はい・いいえ、言語・音の切り替え、記録を消す確認を開く） |
| `sfx/ending.wav` | エンディングの全体（階段の確認で YES を選び、拠点の画面と曲が 1.5 秒かけて消えたところから）。光が強まり得点が使われていく 4.2〜10.2 秒、そのあとも響きが上がり続けて止む 13.2 秒、少女が家に入って戸を閉める 14.1〜15.6 秒、何かが発動する 16.2 秒、その音が鳴りやんで家の青白い光と中の明かりが消える 18.9〜19.1 秒、2 秒ほど静まって轟音が始まる 21.1 秒、家が崩れる 21.3〜28.0 秒（大きく崩れるのは 22.5・24.5・26.1 秒）、揺れが収まる 31.5 秒、静止画になる 34.5 秒（時刻は `src/render/ending.ts` の `ENDING`） |

## 形式

- WAV（16bit か 24bit、44.1kHz か 48kHz）。ステレオでもモノラルでもかまいません。
- 音量はそのまま使います（ゲーム側で揃えない）。曲どうしの音量は元のファイルで揃えてください。

## BPM と長さを試す

曲を作る前にステージの BPM や長さを試すときは、開発サーバーの URL に `?bpm=N` と `?bars=N` を付けます（例：`?stage=STAGE3&autostart&bpm=132`）。そのときだけ変わり、ステージの定義は変わりません。

決めたら `tools/stagegen/` のそのステージの `BPM`・`BARS` を書き換えて `--write` で書き出し、`npm run bots` で、安全な道だけでゴールに着けるか（安全ルートの残り拍数）を確かめます。長さを縮めると、安全な道だけでは間に合わなくなることがあります。
